# deepseek-harness-desktop-wayland 0.2.2rc3-2

在 0.2.2rc3-1 基础上的 **console 零噪音** 修复版（同一官方上游 `dsh-v0.2.2-rc.3`）。

## 修复

- **account 日志**：Linux 没有账户后端，`[deepseek-account] account read failed` 属预期能力缺失；现在 Linux 上完全不记录（此前降级为 info 仍会出现在 DevTools）。
- **changes.summary 404**：`workspace/changes` 摘要只存在于 Host 进程内存，Host 重启后旧轮次的改动卡片请求会 404，浏览器网络面板必然记录错误。现在缺失摘要返回 `200 null`，客户端仍按 "missing" 状态渲染，**UI 行为不变**，console 不再有 404。
- 补丁系列从 16 个增至 17 个（0014 更新、0017 新增）。

## 安装（Arch Linux）

```bash
sudo pacman -Sy
sudo pacman -S deepseek-harness-desktop-wayland   # localrepo 会从 rc3-1 升级到 rc3-2
```

或下载本 Release 的 `.pkg.tar.zst`：

```bash
sudo pacman -U deepseek-harness-desktop-wayland-0.2.2rc3-2-x86_64.pkg.tar.zst
```

安装后完全退出并重启 "DeepSeek Harness"。

## 零 console 报错前提

用户 profile 不要启用实验 bundle `@deepseek-ai/dsh-experimental-inspector-profile`（它会产生 9230 ingest 连接错误，并暴露无认证 CDP 端口）；移除后重启即可。
